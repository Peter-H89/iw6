1.5 Argumenten voor programma’s

OpmerkingLeerdoelen

Na deze les kan je:

  • uitleggen waarom een programma argumenten krijgt
  • uitleggen wat een programma meekrijgt als je het uitvoert met argumenten
  • een module beschikbaar maken met import
  • een argument opvragen met sys.argv[1]
  • een argument omzetten met naar een ander type
  • een programma schrijven dat iets doet met zijn argument

In 1.4 voerde je een programma uit met python3 en de naam van het bestand. Zo’n programma doet telkens hetzelfde. De inhoud ligt vast in de code.

In deze les leer je een techniek om programma’s te laten werken met informatie van buitenaf. Dit kan tekst zijn, of documenten, foto’s, liedjes, films of andere bestandssoorten. Het voorbeeld werkt met foto’s. Voorlopig beperken we ons tot werken met tekst.

Lees de eerste drie secties. Werk vanaf sectie 4 mee in de virtuele machine.

1 Waarom argumenten

Stel dat je honderd foto’s hebt en op elke foto een logo wil zetten.

Je schrijft hiervoor het programma logo.py, en in dat programma staat de naam van de foto. De rest van de code is hier niet van belang.

Als je het logo op de eerste foto hebt gezet, zou je logo.py in micro moeten openen, herfst.jpg vervangen door zonsondergang.jpg, het programma opslaan, en vervolgens het programma opnieuw moeten uitvoeren. En dat zou je dan honderd keer moeten doen…

Een programma dat argumenten aanneemt, laat de specifieke naam van de foto uit de code weg. Je geeft hem in de plaats mee in het commando.

python3 logo.py herfst.jpg
python3 logo.py zonsondergang.jpg

Het programma logo.py blijft bij elke foto hetzelfde, enkel het argument verandert. Deze werkwijze vergemakkelijkt de verwerking van meerdere bestanden.

2 Wat een programma meekrijgt

Een commando bestaat uit een naam, opties en argumenten, gescheiden door spaties, zoals je zag in 1.4. Bij python3 logo.py herfst.jpg is python3 de naam van het commando, en logo.py en herfst.jpg zijn de argumenten.

python3 gebruikt het eerste argument, de bestandsnaam, om je programma te openen. Alles wat erna komt, krijgt je programma mee als een rij woorden.

Elk woord heeft een vaste plaats, en Python nummert die plaatsen vanaf 0. Zo’n genummerde rij heet in Python een lijst, en het nummer van een plaats heet de index. Je vraagt een woord op door zijn index tussen vierkante haken achter de lijst te schrijven. De lijst met de woorden van het commando heet sys.argv.

schrijfwijze levert bij python3 logo.py herfst.jpg 2
sys.argv ['logo.py', 'herfst.jpg', '2']
sys.argv[0] 'logo.py'
sys.argv[1] 'herfst.jpg'
sys.argv[2] '2'
int(sys.argv[2]) 2
WaarschuwingOpgelet

Elk argument is een string, ook 2. Je ziet dat aan de aanhalingstekens in de lijst. Wil je ermee rekenen, dan zet je het om naar een getal met int().

3 De module sys

Je zag in 1.1 dat Python ingebouwde functies heeft, zoals print en len. Die zijn altijd beschikbaar. Daarnaast heeft Python een grote verzameling extra functies en waarden, voor grafieken, afbeeldingen, tijd… Maar je hebt deze niet altijd nodig, dus worden ze niet standaard meegeleverd. Deze zijn gebundeld in aparte modules, en een module maak je beschikbaar met import. sys.argv zit in de module sys.

De regel import sys schrijf je bovenaan je programma. Doorheen je programma moet je steeds sys. schrijven voor de functionaliteit die je uit die module wil gebruiken. Het programma toon-argumenten.py bestaat uit twee regels en toont met behulp van de module sys de lijst met argumenten die wordt meegegeven.

$ python3 toon-argumenten.py 5 groen
['toon-argumenten.py', '5', 'groen']

4 In de virtuele machine

Vanaf hier typ je elk blok over, zoals in 1.4. Je werkt in ~/iw6.

Elk bestand in deze les telt hooguit vijf regels, en er kan niets misgaan. Loop je vast, of maakte je een map of bestand met een verkeerde naam, verwijder dan met rm en rmdir uit 1.4 tot je weer met een schone lei begint.

cd ~/iw6
micro toon-argumenten.py

Ctrl-S bewaart het bestand en Ctrl-Q sluit micro af.

$ python3 toon-argumenten.py 5 groen
['toon-argumenten.py', '5', 'groen']
$ python3 toon-argumenten.py
['toon-argumenten.py']

Zonder argumenten bevat de lijst enkel de bestandsnaam. Het programma groet.py gebruikt één argument.

micro groet.py
$ python3 groet.py Lena
Hallo Lena
$ python3 groet.py Jan
Hallo Jan

Het bestand blijft hetzelfde, de uitvoer volgt het argument. Het programma verdubbel.py rekent met zijn argument, en gaat dus eerst door int().

micro verdubbel.py
$ python3 verdubbel.py 21
42

5 Conclusie

Een programma met argumenten laat de gegevens uit zijn code weg en krijgt ze mee in het commando. import sys maakt de module sys beschikbaar. sys.argv is een lijst met de naam van het bestand op index 0 en het eerste argument op index 1. Elk argument is een string, en int() zet het om in een getal.

6 Begrippen

  • argument (argument): een woord dat je in het commando na de bestandsnaam typt en dat je programma meekrijgt.
  • lijst (list): een rij waarden tussen vierkante haken.
  • index (index): het getal dat de plaats van een waarde in een lijst aangeeft, en dat je tussen vierkante haken achter de lijst schrijft. De eerste plaats heeft index 0.
  • module (module): een verzameling functies en waarden die je met import beschikbaar maakt.
  • sys.argv: de lijst met de naam van het bestand op index 0, gevolgd door de argumenten van het commando.

7 Oefeningen

  1. Vervang in toon-argumenten.py de regel print(sys.argv) telkens door de regel hieronder, en start met python3 toon-argumenten.py 7. Schrijf op wat er verschijnt, zonder de computer.

    1. print(sys.argv)
    2. print(sys.argv[1] * 2)
    3. print(int(sys.argv[1]) * 2)
    TipAntwoord

    a. ['toon-argumenten.py', '7'].

    b. 77. sys.argv[1] is de string '7', en * herhaalt een string, zoals in 1.2.

    c. 14. int() zet '7' om in het getal 7, en 7 * 2 is 14.

  2. Je start een programma som.py met python3 som.py 3 4.

    1. Schrijf op wat print(sys.argv) en print(sys.argv[1] + sys.argv[2]) tonen.
    2. Schrijf som.py zodat het de som van de twee argumenten toont.
    TipAntwoord

    a. ['som.py', '3', '4'] en 34. De argumenten zijn strings, en + plakt twee strings aan elkaar.

    b.

  3. Schrijf tafel.py zodat python3 tafel.py 7 de tafel van 7 toont, met de lus uit 1.3.

    TipAntwoord

  4. Schrijf kortingsprijs.py zodat python3 kortingsprijs.py 19.99 15 de prijs na 15 procent korting toont, afgerond op centen. Een argument dat een kommagetal voorstelt, zet je om met float().

    Er verschijnt 16.99. int("19.99") loopt vast, zoals in 1.2, dus beide argumenten gaan door float().
